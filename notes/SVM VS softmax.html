什么是 SVM？它与 Softmax 到底有什么区别？

这两个名字容易让人误以为是两套完全不同的分类系统。实际上，在这页 CS231n 笔记里，它们共享同一个“前半段”：都用 W 把图片变成类别分数；真正不同的是“后半段”——它们怎样解释这些分数，以及怎样定义“做得不好”。

因此，理解这整页最有效的切入点不是分别死记两个公式，而是先抓住：同一组 scores，SVM 用间隔判断好坏，Softmax 用概率判断好坏。
图片 x→线性打分 f = Wx + b→SVM：检查分数间隔或Softmax：变成概率→计算损失并调整 W

共同起点：线性分类器只负责“打分”

对第 i 张图片 xi，分类器先计算：

f(xi, W, b) = W xi + b输入一张图片，输出每个类别各自的分数

若有 K 个类别、每张图片展开后有 D 个数，那么：

WK × D
每一行负责一个类别

例如 CIFAR-10 有 10 个类别，每张图片有 32×32×3=3072 个像素值，因而 W 的形状是 10×3072，x 的形状是 3072×1，乘完得到 10×1 的分数向量。一行 W 相当于一个类别的“模板”：它与图片做点积，匹配得越好，分数越高。

W.dot(x) 为什么会得到 scores？ 因为 dot 是 NumPy 的矩阵乘法方法。W 的每一行分别与 x 做一次点积，正好得到每个类别的一个分数。

到这里，SVM 和 Softmax 完全一样。它们都可用同一个 W、同一个 b、同一组 scores；区别从“损失函数”开始。损失函数就是把当前预测压缩成一个数：数越大，表示当前 W 越不符合训练标签。

SVM：不仅要选对，还要“赢得够明显”

假设第 i 张图片真实类别是 yi。SVM 的直觉是：正确类别分数不仅要最高，还要比每一个错误类别至少高出固定间隔 Δ。

Li = Σj ≠ yi max(0, sj − syi + Δ)第 i 张图片的损失 = 所有错误类别各自的间隔缺口之和

这里 sj 是第 j 类分数，syi 是正确类别分数。对每个错误类别分别计算：

max(0, Δ −（正确类别实际领先的分数）)领先达到 Δ：处罚为 0；还差多少：处罚多少

小例子：正确答案是猫，Δ = 10

猫（正确）13
狗11
汽车−7
比较计算含义损失
狗 vs 猫max(0, 11−13+10)猫只领先 2，还差 8 才达到间隔 108
汽车 vs 猫max(0, −7−13+10)猫领先 20，已经越过安全线0

所以 Li = 8。

注意：猫分数 13 已经最高，最终预测并没有错；但它只比狗高 2，没有达到要求的 10，所以仍然受罚。SVM 衡量的不是单纯“预测对没对”，而是：正确类别对每个错误类别的领先是否足够稳。

SVM 不是先把所有错误分数合起来再减正确分数。它让狗、汽车等每个错误类别分别和猫比较，最后把所有正的处罚相加。

代码里的 margins 为什么是数组？

# scores = [猫, 狗, 汽车]
scores = [13, 11, -7]
y = 0
delta = 10

scores - scores[y] + delta
→ [10, 8, -10]

np.maximum(0, ...)
→ [10, 8, 0]   # np.maximum 是逐元素比较，不是找一个最大值

margins[y] = 0
→ [0, 8, 0]    # 清除正确类别与自己比较产生的假损失

np.sum(margins)
→ 8            # 最后才得到标量 L_i

当一张图片的所有错误类别都至少落后 Δ 时，Li=0。这体现了 SVM 的“达标制”：超过安全间隔以后，继续把正确分数推得更高，不会让数据损失继续下降。

为什么 SVM 还要加正则化？

只看间隔损失会留下一个问题：若某个 W 已经分得很好，把整个 W 乘以 2，所有分数和分数差也会乘以 2，但预测类别和分类边界并没有改变。分数差看起来更大，可能只是把尺子的刻度放大了。

W → 2W  ⇒  scores → 2 scores  ⇒  类别排序不变W、2W、100W 可能完成同样的分类工作，仅凭数据损失无法选择

因此，完整目标会加入 L2 正则化：

L = (1/N) ΣiLi + λ Σk,lWk,l2总损失 = 平均数据损失 + 权重过大的处罚
  • W 太小：各类别分数挤在一起，间隔不足，数据损失大。
  • W 太大：即使分类没变，权重平方和也会变大，正则化损失大。
  • 训练寻找平衡：用不过分膨胀的 W，获得尽量正确且有间隔的分类。

L2 也倾向于让影响分散到多个输入维度，而不是让少数像素拥有极端大的权重。这通常会降低模型对训练数据中偶然细节的依赖，从而减轻过拟合。

Δ 通常固定为 1。因为把 Δ 从 1 改成 100，可以通过放大 W 来适配；真正需要调的是 λ——我们允许 W 为了降低数据损失增长到什么程度。
二分类 SVM 的常见写法是 C·max(0, 1−yiwTxi) + R(W)，其中 y∈{−1,+1}。它和这里的多分类 SVM 使用同一种“间隔不足就处罚”思想；C 越大越看重数据损失，而 λ 越大越看重正则化，所以两者作用方向相反。

Softmax：把同一组分数解释成概率

Softmax 并没有换掉打分函数。仍然是：

f(xi, W) = W xi变化的不是分数怎样产生，而是分数怎样被解释和处罚

Softmax 先把任意实数分数转成一组 0 到 1 之间、总和为 1 的数：

qj = efj / Σkefkq_j 是模型分给第 j 个类别的归一化概率

分母本来就等于所有分子之和，因此全部概率相加一定是 1。这里没有使用“同底数幂相加”的规则；只是同分母分数相加：

ef₁/S + ef₂/S + ··· + efK/S = (ef₁+···+efK)/S = S/S = 1

小例子：原始分数 [3, 2, 0]

先做指数：e³≈20.09，e²≈7.39，e⁰=1；总和约为 28.48。所以 Softmax 概率约为：

交叉熵为什么只剩下正确类别概率？

真实答案可以写成 one-hot 分布。若猫是正确类别：

p = [1, 0, 0]    H(p,q) = −Σjpjlog qj = −log q猫

因为错误类别位置的 p 都是 0，乘完不会贡献损失。所以单张图片的 Softmax 交叉熵损失就是：

Li = −log ( efyi / Σjefj ) = −fyi + log Σjefj它在问：模型给正确类别分配了多少概率？

两个写法相等，是因为 log(a/b)=log a−log b，且自然对数满足 log(ex)=x。正确类别概率越接近 1，−log(qy) 越接近 0；若模型几乎不给正确类别概率，损失会迅速变大。

Softmax 本身只是“分数 → 概率”的函数；真正计算损失的是交叉熵。但实际交流中，人们经常把 Softmax 与交叉熵的组合简称为 “Softmax loss”。

数值稳定性：为什么代码总先减去最大分数？

指数函数增长非常快，直接算 e789 可能超过浮点数表示范围。Softmax 有一个重要性质：所有分数同时减去同一个常数，结果不变。

efj−M / Σkefk−M = efje−M / ( e−MΣkefk )分子分母共同因子 e^(−M) 抵消
scores = np.array([123.0, 456.0, 789.0])

scores = scores - np.max(scores)
# [-666., -333., 0.]

exp_scores = np.exp(scores)
probs = exp_scores / np.sum(exp_scores)

取 M=max(scores) 后，最大分数变成 0，其指数是 e⁰=1，其余指数不超过 1，从而显著降低上溢风险。

同一组分数，SVM 和 Softmax 为什么会有不同态度？

SVM：间隔是否达标

正确类别只要比每个错误类别至少高 Δ，就不再处罚。达标以后继续增大分差，数据损失仍为 0。

Softmax：正确概率有多高

只要正确类别概率还没到 1，损失就仍然大于 0。它会持续鼓励正确分数更高、错误分数更低。

并排比较：正确类别都是第一类

这正是二者最核心的差别：SVM 是“越过安全线即可”，Softmax 是“继续提高正确答案在全部类别中的相对占比”。

这页中几处容易被带偏的地方

“SVM 是一整个不同的打分模型。”
在这页里，SVM 和 Softmax 都先用同一线性函数打分；不同的是损失函数。
“Li>0 就表示预测错了。”
SVM 中不一定。预测可以正确，但领先不够 Δ。
“np.maximum 会找出最大的错误类别。”
它逐元素与 0 比较，保留所有正 margin；最后再求和。
“Softmax 的指数分子相加是用了幂的加法公式。”
不是。分母直接定义成所有分子的和，所以各比例之和自然为 1。
“Softmax 概率就是客观真实概率。”
它是模型内部的归一化置信度；概率数值还会受权重尺度、正则化和校准情况影响。
“正则化就是把 W 压到越小越好。”
若 W=0，分类能力也消失。训练寻找的是数据损失与权重大小之间的平衡。

把整页重新串起来

  • 把图片像素展开为 x，用 W x+b 同时计算所有类别分数。
  • 损失函数评价当前分数与真实标签是否一致，并指导之后怎样调整 W。
  • SVM 逐个检查错误类别：正确类别有没有至少领先 Δ；所有缺口相加得到 Li。
  • 正则化限制 W 无意义地膨胀，并减少对少数输入维度的极端依赖。
  • Softmax 把同一组分数指数化、归一化为概率，再用 −log(正确类别概率) 计算交叉熵。
  • 二者都在找低损失的 W，只是 SVM 追求“有间隔地分对”，Softmax 追求“让正确类别概率尽量高”。

记住这一点

SVM 和 Softmax 共享同一个分数函数；它们的根本区别在于怎样定义“好的分数”。

SVM 要求正确类别对每个错误类别留出固定安全间隔，达标即停止处罚；Softmax 把分数变成概率，用交叉熵持续提高正确类别的概率。

两者都要配合正则化寻找 W：既让训练标签得到合理分数，又避免权重无意义地过大。
